# Changelog

## 1.1.0 — 2026-10-22

- **One image for virtual machines and the Raspberry Pi.** `linuxmint-22.3-cinnamon-arm64-unofficial.img.xz` starts in a virtual machine (UEFI, GRUB, the hardware-enablement kernel) and on a Raspberry Pi 4, 400, CM4, 5, 500 or CM5 (the Pi's firmware, Ubuntu's Raspberry Pi kernel with the Pi's firmware only), from the same boot partition. At its first start it removes what its machine does not use: in a VM the Raspberry Pi's kernel, firmware and boot tools, and Bluetooth, Wi-Fi, printing and scanning; on a Pi the VM's kernel, GRUB and guest tools. It then runs Linux Mint's setup. The ready-made UTM VM is that image on a 64 GB disk, with its first start in a VM already done.
- **On the Raspberry Pi**: written with Raspberry Pi Imager, laid out like Ubuntu's Raspberry Pi images; the system grows to fill the card; Ubuntu's Raspberry Pi kernel and desktop settings, with the Pi's firmware for its GPU, Wi-Fi, Bluetooth and sound (Wi-Fi power saving off); kernel updates go onto the boot partition through `flash-kernel`, and the bootloader keeps itself up to date as on Ubuntu and Raspberry Pi OS. **Not yet tested on a real Raspberry Pi**: this release was tested with the Pi's own kernel in QEMU on a Mac (first start, setup, desktop, a kernel update through `flash-kernel`).
- **No ISO any more.** The image comes installed, so the live session, the installer and `casper` are gone. A VM of your own takes the image as its disk, Apple's Virtualization framework (for Rosetta) included.
- **Update Manager** offers no other kernel line when the running kernel is of a flavour it does not support, the Raspberry Pi's: it used to offer Ubuntu's generic PC kernel there.
- **Settings in three packages**: `mint-arm-system` keeps what every machine shares and the first-start service, `mint-arm-vm` the VM's Firefox rendering setting and the Rosetta service, `mint-arm-pi` the Pi's boot chain. A VM from 1.0.0 that installs this release's `mint-arm-repo` package gets `mint-arm-vm` automatically through Update Manager, which updates itself first and offers the rest at its next check.
- **The build** makes the image and the VM (`./build.sh`), and with `--test-ssh` a test image that can be reached over SSH, for testing on a real Pi. New test tools: `testpi.sh` starts the image as a Raspberry Pi does, in QEMU on the Mac, and `pitest.sh` checks a Pi over SSH.

## 1.0.0 — 2026-10-21

First public release, in the public domain (The Unlicense).

- **Linux Mint 22.3 "Zena" Cinnamon for ARM64**, made from the package list of Linux Mint's official x86 ISO: Cinnamon 6.6.9, the X-Apps, Linux Mint's tools and artwork, its installer with live session and OEM mode. All 48 Linux Mint source packages with compiled code are rebuilt for ARM64; Ubuntu 24.04's ARM64 archive provides the base, with Linux Mint's kernel line, Ubuntu's hardware-enablement kernel (7.0, *virtual* flavour).
- **Two ways to get it**: a ready-made UTM virtual machine, preinstalled in OEM mode so that its first start runs Linux Mint's setup, and a live/install ISO for UTM or any VM app that boots ARM64 UEFI images.
- **Light for a VM**: a 1.65 GB ISO (3.09 GB for Linux Mint's x86 ISO) and about 1,600 packages instead of 2,005. Firmware and drivers for hardware a VM does not have are left out, and the large applications are a click away.
- **GPU-accelerated desktop** on UTM's *GPU Supported* display (virglrenderer and ANGLE onto Metal); Firefox draws in software there, because it lost its text through UTM's OpenGL.
- **Updates that keep working**: Software Sources patched for Ubuntu's ARM mirrors; Update Manager patched to recognise the kernel line, so it never offers the 64k-page kernel that Apple silicon cannot start; Firefox from Mozilla's ARM64 repository; Linux Mint's packages in a local signed archive with Linux Mint's own priority, so Ubuntu's never replace them; Ubuntu's snap-only Firefox, Thunderbird and Chromium packages hidden; Firefox language packs that install Mozilla's.
- **Made for a VM**: compressed RAM swap, clipboard sharing and automatic resizing, shared folders, the QEMU guest agent, VMware Fusion's tools, a smaller journal, and Rosetta for x86-64 programs under Apple's Virtualization framework (with Ubuntu's 6.8 kernel: Rosetta does not yet run programs on newer kernels).
- **One-command build** on a Mac (`./build.sh`, about 35 minutes on an M4 Max), headless test tools including UTM's own QEMU with its GPU display, and a release script that collects the source code of every rebuilt package.
